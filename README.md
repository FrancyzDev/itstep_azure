**Items Manager** - веб-додаток для керування товарами з можливістю автоматичного перекладу назв товарів на різні мови за допомогою **Azure Cognitive Services Translator**

Приклади використання:
1. **Зберігати одну версію товару** в базі, а переклад виконувати "на льоту"
2. **Економити місце** в базі даних
3. **Швидко додавати нові мови** без змін у структурі даних
